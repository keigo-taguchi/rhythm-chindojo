# リズム珍道場

ちょっとヘンなリズム修行が全20ステージ入った、ブラウザで遊べるリズムゲームです。
ボタンひとつ（ステージによっては2つ）で、音と動きに合わせてタイミングよく押します。

**▶ 遊ぶ：https://keigo-taguchi.github.io/rhythm-chindojo/**

## 操作

- **A**：`Space` / `J` / `Z`、または画面タップ（長押しあり）
- **B**：`F` / `X`、または画面の右半分
- **やめる**：`Esc`

判定がずれると感じたら、タイトル画面の「タイミング調整」で合わせてください。

## 中身

- `index.html` 1枚で完結しています（ビルド不要・外部ライブラリなし）。
- 絵はすべて Canvas で描画、BGM と効果音はすべて Web Audio API でその場で合成しています。
- キャラクター・曲・ステージはすべてオリジナルです。任天堂および「リズム天国」シリーズとは関係のないファンメイド作品です。
